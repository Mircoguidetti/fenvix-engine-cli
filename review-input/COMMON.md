# Common rules for work and reviewer sessions

- Repositories: fenvix-brain-cli (read `CLAUDE.md`, `NOW.md`, your component file in `components/`) and fenvix-engine-cli. Read anything else only if your task needs it.
- Everything you write is in English. You do not talk to the founder: you talk to the coordinator through your report.
- Work only on your branch. Small commits, push often, draft PR at the end. Never merge, never delete branches.
- No spending of any kind, no personal connectors, no contact with project maintainers or companies.
- Every number carries a label: MEASURED, ESTIMATED, DECLARED (with source) or UNKNOWN. Timings taken while the host is shared are NOISY.
- Your prompt's "Done means" is the contract. Run every test before you deliver.
- If something blocks you, stop and write what blocks you. Do not hide a problem behind a timeout or a skipped test.
- Deliver: write `sessions/YYYY-MM-DD-<name>/REPORT.md` (intermediate deliveries `INTERMEDIATE-1.md`, `INTERMEDIATE-2.md`…) in fenvix-brain-cli and push it to `main` as `sessions/README.md` explains. In chat write only: `Report ready: <path>`.
- Model: Opus 5.5 with high effort, or Fable 5.2 (RULES.md, "Models").
